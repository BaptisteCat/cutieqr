Modules

Fond

Le fond transparent est conservé en PNG, WebP, SVG et PDF. Le JPEG, qui ne le gère pas, reçoit un fond blanc — ou sombre si vos modules sont clairs.

Modules

Yeux — contour

Yeux — centre

Un contour et un centre de même forme se lisent le mieux. Les mélanges (contour carré, centre rond…) peuvent gêner certains lecteurs, surtout sur les QR codes denses : surveillez le voyant de lecture sous l’aperçu.

Lisibilité

Plus la correction est élevée, plus le QR code tolère un logo ou une salissure — mais plus il est dense.

Ajouter un logo PNG, JPEG, SVG ou WebP — glissez l’image ici ou choisissez un fichier.
Forme de la zone

Un logo masque une partie du code : gardez-le sous 25 % et vérifiez le voyant de lecture sous l’aperçu.

Police

Enregistrer le style actuel

Un modèle retient les couleurs, les formes, le logo et le cadre — pas le contenu.

Mes modèles

Prêts à l’emploi

Chaque QR code exporté ou enregistré est conservé ici, sur cet appareil uniquement.

La sauvegarde (modèles + historique) est un fichier à restaurer sur un autre appareil pour y retrouver vos créations.

Synchronisation entre appareils

Gist GitHub privé Vos modèles et votre historique, identiques sur tous vos appareils.

Créez un jeton GitHub limité aux Gists, puis collez-le ici. Faites de même sur chaque appareil : ils partageront le même Gist secret.

Créer un jeton sur GitHub

Le jeton reste sur cet appareil et ne sert qu’à lire et écrire votre Gist « CutieQR ». Un Gist secret n’apparaît nulle part publiquement, mais toute personne qui en obtient l’adresse peut le lire, contenus compris (contacts, IBAN, logos) : réservez la synchronisation à des données que vous accepteriez de voir circuler.
